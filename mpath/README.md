# MPath

MPath means "Marjinel's Path" and "My Path." It is a premium Computer Science career aptitude assessment that recommends one best-fit technology career path.

## Features

- Professional landing page
- One-question-per-screen assessment flow
- Balanced randomized question selection
- 7-point Likert scale
- Weighted psychometric scoring
- One final role result only
- LocalStorage progress persistence
- Resume, restart, and retake flows
- Responsive design
- Reusable component architecture
- API route for assessment generation and scoring

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- LocalStorage persistence

## Setup

```bash
npm install
npm run dev
```

Open:

http://localhost:3000
